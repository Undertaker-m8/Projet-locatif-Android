# 🏠 Student Housing Manager

An Android application designed to simplify student housing management,
built with **Java** on **Android Studio**.

---

## ✨ Features

- 🎓 Student registration and profile management
- 🏘️ House listing and availability tracking
- 🏘️ Rating and Data Storage
- 📅 Booking and rent management
- 🗺️ Interactive map visualization via **OpenStreetMap (OSM) API**
- ☁️ Real-time data storage with **Firebase**

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Mobile Front-end | Android Studio (Java) |
| Database | Firebase (Firestore) |
| Map Integration | OpenStreetMap API |
